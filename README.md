# Fruit Quality Detection

This repository originally stated the goal of classifying fruit quality as **Good or Bad**, but it did not contain a dataset, trained model, feature definitions, or training code.

The working image-upload and Explainable AI implementation is maintained here:

**[Fruit Quality XAI Lab — Streamlit + LIME](https://github.com/Vinodvinum/xai-lime-classroom-demo)**

The demo uses a real public dataset and an attributed image-classification model. It supports image upload, fruit-type/freshness prediction, side-by-side results with and without XAI, and LIME image-region explanations.

## Original project status

- Original repository contents: README only.
- Intended task: fruit-quality classification.
- Original model architecture and preprocessing: not specified in this repository.
- Original training dataset and features: not supplied in this repository.

See the XAI Lab repository for the dataset source, model card, implementation, limitations, and optional model fine-tuning script.
